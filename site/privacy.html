ATRIL — Privacy Policy

Last updated: October 7, 2026. ATRIL is a personal desktop application used by a single channel owner to prepare, review and upload videos to their own YouTube channel.

What ATRIL accesses

  • YouTube API Services. With the channel owner's explicit OAuth consent, ATRIL uploads videos and thumbnails the owner has approved, and reads the owner's channel name and the status of uploaded videos.

Where data is stored

All data stays on the owner's computer. OAuth tokens and API keys are stored in the Windows Credential Manager. ATRIL has no server and does not send YouTube data to any third party. Content the owner submits for text generation, speech synthesis or image generation is sent only to the providers the owner configures (Anthropic, Google, and optionally OpenAI or ElevenLabs), under their respective terms. Search terms are sent to the free media libraries the owner enables (such as Pexels, Pixabay, Wikimedia Commons, Openverse, NASA, The Met and Freesound) to find openly licensed media.

Use of YouTube API Services

ATRIL uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from ATRIL (Settings → YouTube → Disconnect) or at myaccount.google.com/permissions. Deleting ATRIL's data folder removes all locally stored information.
